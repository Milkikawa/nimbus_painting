# Changelog

## 0.3.0 - 管理后台视觉与交互升级

### 已加入

- 管理后台升级为更统一的 iOS 风格视觉系统，覆盖布局、卡片、表格、按钮、空状态和暗色模式。
- 概览页新增更直观的 KPI 卡片和模型统计信息，便于快速了解服务运行状态。
- 提示词组页面调整为正向/负向提示词分栏布局，提升提示词配置和维护效率。
- 侧边栏导航加入更清晰的状态指示，后台各页面切换体验更加一致。

### 改进

- 拆分前端样式为 tokens、base、layout、components、pages、dark 等模块，降低后续维护成本。
- 重构基础设置、运行监测、图片管理和请求日志页面，优化信息层级、卡片结构和响应式表现。
- 优化请求日志与图片管理页的信息密度，提升移动端和窄屏场景下的可读性。
- 暗色模式样式独立维护，减少全局样式耦合。

### 注意事项

- 本次主要为 WebUI 体验升级，后端接口和数据结构无破坏性变化。
- 如有自定义前端样式，需要根据新的 CSS 模块结构进行适配。

## 0.2.0 - WebUI 多视图与项目监测

### 已加入

- WebUI 重构为 `/dashboard` 单入口多视图后台，支持概览、项目监测、基础设置、提示词组、图片管理和请求日志。
- 新增初始化/登录状态接口，页面会根据当前状态展示初始化、登录或后台主界面。
- 新增项目监测面板，展示进程运行状态、图片统计、任务统计和成功率快照。
- 前端静态资源拆分为独立 CSS、API 封装和页面模块，页面数据改为按需加载。

### 改进

- 优化后台视觉效果，加入侧边栏导航、卡片布局、空状态、错误提示和响应式表格。
- 监测数据不做后台采样、不自动轮询，仅在打开页面或手动刷新时读取，降低资源开销。

### 验证情况

- 已补充状态接口和监测接口测试。
- 已通过工作区缓存下的 `go test ./...` 验证。

## 0.1.0 - 初始框架版

### 已加入

- Go 单体 HTTP 服务。
- OpenAI 兼容接口：`/v1/models`、`/v1/chat/completions`。
- 对 NewAPI 只暴露 `sd-generate` 和 `sd-edit`。
- `sd0` 到 `sd13` 支持普通生图，`sd14` 作为编辑模型保留但暂不实现。
- Prompt 参数解析：`sdX`、`宽*高`、`--seed`、`--steps`、`--cfg`。
- 未指定 seed 时由本服务本地生成随机 seed。
- 上游 `Authorization` 仅透传，不保存。
- 图片下载保存到本地，并通过 `/images/...` 访问。
- WebUI：首次初始化密码、登录、基础设置、提示词组、请求日志、图片管理。
- SQLite WAL 和 MariaDB 支持。
- Dockerfile、docker-compose、`.env.example`。

### 暂未加入

- 真正的图片编辑链路。
- 真实进度流式输出。
- 图片批量打包下载。
- MariaDB / SQLite 之间的数据迁移。
- PostgreSQL 实现。
