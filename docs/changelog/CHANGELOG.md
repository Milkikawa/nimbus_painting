# Changelog

## 0.5.0 - 可配置上游模型目录

### 已加入

- 新增文件驱动的上游模型能力目录，默认持久化到 `MODEL_CATALOG_PATH` 指定的 JSON 文件。
- 管理后台新增「模型目录」页面，可增删改模型索引、ID、本地显示名、类型、启用状态和特殊参数规则。
- 新增 `/admin/api/models` 管理接口，用于读取和保存当前模型目录。

### 改进

- 图片生成链路、`/v1/models`、默认模型校验和特殊模型参数兼容均改为读取可配置目录。
- 自然语言文生图类模型的强制步数与是否追加默认正面提示词改为目录规则控制。
- Docker 配置新增 `MODEL_CATALOG_PATH`，模型目录随 `/app/config` 挂载持久化。

### 注意事项

- 本地模型目录只影响未来请求、当前 UI 展示和请求前兼容规则。
- 请求日志、图片记录和统计中的实际模型名仍以上游响应体 `model_name` 为准，不会由本地目录名称反向改写。
- 已通过 `go test ./...`、`node --check` 和 `go build ./cmd/server` 验证。

## 0.4.0 - 上游模型目录与兼容性更新

### 已加入

- 新增集中式上游模型目录，用于统一维护内置模型索引、模型 ID、模型类型和可用状态。
- `/v1/models` 增加返回内置上游模型元数据，便于调用方识别当前服务可用的图片模型与暂不可用模型。
- 新增基于模型目录的图片生成模型校验，避免将不支持或暂不可用的模型请求继续转发到上游。

### 改进

- 将旧的模型索引硬编码范围校验调整为目录驱动校验，后续上游模型列表更新时优先维护集中目录。
- 更新内置上游模型目录至当前上游数据版本，并保留暂不支持的视频模型占位与禁用状态。
- 默认模型配置现在会校验是否为可用图片模型；如历史配置不可用，运行时会回退到安全默认模型。
- 对自然语言文生图类模型增加专门参数兼容处理：固定使用推荐步数，并避免附加默认质量提示词。

### 修复

- 修复旧逻辑中某个图片模型索引被误判为仅编辑模型的问题。
- 修复模型列表更新后旧的 `0-13` 范围限制导致新增图片模型无法使用的问题。
- 避免视频类或暂不可用模型被误用于图片生成链路。

### 注意事项

- 上游模型索引复用仍是后续需要重点处理的风险点；相关分析已写入被忽略的开发文档目录。
- 已通过 `go test ./...` 验证。

## 0.3.0 - 管理后台视觉与交互升级

### 已加入

- 管理后台升级为更统一的 iOS 风格视觉系统，覆盖布局、卡片、表格、按钮、空状态和暗色模式。
- 概览页新增更直观的 KPI 卡片和模型统计信息，便于快速了解服务运行状态。
- 提示词组页面调整为正向/负向提示词分栏布局，提升提示词配置和维护效率。
- 侧边栏导航加入更清晰的状态指示，后台各页面切换体验更加一致。

### 改进

- 拆分前端样式为 tokens、base、layout、components、pages、dark 等模块，降低后续维护成本。
- 重构基础设置、运行监测、图片管理和请求日志页面，优化信息层级、卡片结构和响应式表现。
- 优化请求日志与图片管理页的信息密度，提升移动端和窄屏场景下的可读性。
- 暗色模式样式独立维护，减少全局样式耦合。

### 注意事项

- 本次主要为 WebUI 体验升级，后端接口和数据结构无破坏性变化。
- 如有自定义前端样式，需要根据新的 CSS 模块结构进行适配。

## 0.2.0 - WebUI 多视图与项目监测

### 已加入

- WebUI 重构为 `/dashboard` 单入口多视图后台，支持概览、项目监测、基础设置、提示词组、图片管理和请求日志。
- 新增初始化/登录状态接口，页面会根据当前状态展示初始化、登录或后台主界面。
- 新增项目监测面板，展示进程运行状态、图片统计、任务统计和成功率快照。
- 前端静态资源拆分为独立 CSS、API 封装和页面模块，页面数据改为按需加载。

### 改进

- 优化后台视觉效果，加入侧边栏导航、卡片布局、空状态、错误提示和响应式表格。
- 监测数据不做后台采样、不自动轮询，仅在打开页面或手动刷新时读取，降低资源开销。

### 验证情况

- 已补充状态接口和监测接口测试。
- 已通过工作区缓存下的 `go test ./...` 验证。

## 0.1.0 - 初始框架版

### 已加入

- Go 单体 HTTP 服务。
- OpenAI 兼容接口：`/v1/models`、`/v1/chat/completions`。
- 对 NewAPI 只暴露 `sd-generate` 和 `sd-edit`。
- `sd0` 到 `sd13` 支持普通生图，`sd14` 作为编辑模型保留但暂不实现。
- Prompt 参数解析：`sdX`、`宽*高`、`--seed`、`--steps`、`--cfg`。
- 未指定 seed 时由本服务本地生成随机 seed。
- 上游 `Authorization` 仅透传，不保存。
- 图片下载保存到本地，并通过 `/images/...` 访问。
- WebUI：首次初始化密码、登录、基础设置、提示词组、请求日志、图片管理。
- SQLite WAL 和 MariaDB 支持。
- Dockerfile、docker-compose、`.env.example`。

### 暂未加入

- 真正的图片编辑链路。
- 真实进度流式输出。
- 图片批量打包下载。
- MariaDB / SQLite 之间的数据迁移。
- PostgreSQL 实现。
