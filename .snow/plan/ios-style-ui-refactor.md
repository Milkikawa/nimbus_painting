# iOS 美学 Web UI 重构方案

## 背景与目标

**项目**：Nimbus Painting Proxy - OpenAI 兼容绘图转发服务的管理后台

**当前状态**：

- 单页 HTML 应用（`dashboard.html`）+ 模块化 JavaScript（`app.js` + `pages/*.js`）
- 基础 CSS 样式系统（`app.css`），支持 Light/Dark 双主题
- 功能完善：认证、导航、概览、监测、设置、提示词组、图片管理、日志查看

**重构目标**：
在保持现有功能逻辑与架构不变的前提下，全面提升视觉体验至 iOS 设计美学标准：

1. **视觉风格**：大圆角（16-20px）、毛玻璃效果（backdrop-filter）、柔和阴影、细腻边框
2. **色彩系统**：暖色调柔和视觉（米白/浅灰背景，温暖中性色），Light/Dark 双主题自动切换
3. **空间感**：增加内边距与间距，消除拥挤感，优化长文本换行
4. **响应式**：完美适配移动端触控（44px+ 触控目标）与桌面端鼠标操作
5. **动效**：实现平移、缩放、状态过渡的流畅动画（spring 曲线、适度缓动）
6. **性能**：保持轻量化，确保低开销运行

**核心约束**：

- ✅ 允许：全面重构 CSS 样式、调整组件结构和类名、增加动效元素
- ❌ 禁止：修改任何业务逻辑、破坏现有功能流程、改变 API 调用逻辑
- ✅ 必须：代码结构清晰、注释准确、符合 iOS HIG 设计原则

## 分析

### 影响的文件

**核心改动**：

- `web/assets/app.css` - **全面重构**，应用 iOS 设计系统
- `web/dashboard.html` - **轻微调整**，优化语义化结构和类名（不改变元素层级）

**保持不变**：

- `web/assets/app.js` - 业务逻辑、路由、状态管理
- `web/assets/api.js` - API 封装
- `web/assets/pages/*.js` - 各页面渲染逻辑

### 技术栈

- 纯 HTML5 + 原生 ES6 模块
- CSS3（CSS 变量、Grid、Flexbox、backdrop-filter、transitions、animations）
- 无框架依赖，轻量化原则

### 复杂度评估

**复杂度**：中等

**原因**：

- CSS 重构范围大（574 行 → 预计 800+ 行，需增加高级视觉效果）
- 需精细调整主题变量、组件样式、响应式布局、动效曲线
- 必须确保 Light/Dark 双主题一致性
- 需兼顾桌面端（鼠标）与移动端（触控）交互体验

### 风险区域

1. **毛玻璃效果兼容性**：`backdrop-filter` 在旧浏览器可能不支持，需提供降级方案
2. **性能影响**：过度使用阴影、模糊、动画可能影响低端设备性能
3. **主题一致性**：Light/Dark 模式下的对比度、可读性需反复验证
4. **响应式断点**：当前 980px/640px 断点可能需微调以适应新视觉密度
5. **长文本处理**：表格、日志、提示词等需确保在大字号、大内边距下不溢出

## 风险与缓解措施

| 风险                       | 影响 | 缓解措施                                                                |
| -------------------------- | ---- | ----------------------------------------------------------------------- |
| 毛玻璃效果浏览器兼容性     | 中   | 使用 `@supports` 提供降级方案（半透明纯色背景）                         |
| 过度动效影响性能           | 中   | 使用 `will-change`、限制动画范围、支持 `prefers-reduced-motion`         |
| 主题对比度不达标           | 高   | 每个颜色变量通过 WCAG 对比度计算器验证                                  |
| 响应式断点不适配新视觉密度 | 中   | 预先计算内容宽度，必要时调整断点（如 980px → 1024px）                   |
| 长文本溢出或折行异常       | 低   | 统一使用 `overflow-wrap: break-word` + `word-break: break-word`（中文） |
| 触控目标过小导致误触       | 高   | 所有可交互元素 `min-height/min-width ≥ 44px`                            |

## 技术细节参考

### iOS 设计原则

- **圆角**：卡片 24px、按钮 12-16px、输入框 10-12px
- **阴影**：多层柔和阴影，避免单一重阴影
- **毛玻璃**：`backdrop-filter: blur(20px) saturate(180%)`
- **间距**：8px 基数，组件间距 16-24px
- **触控目标**：最小 44x44px（iOS HIG 标准）
- **动效**：`cubic-bezier(0.4, 0.0, 0.2, 1)`（Material）或 `cubic-bezier(0.25, 0.1, 0.25, 1)`（iOS）

### 色彩参考

- **Light 主题背景**：#F8F7F5（米白）、#FFFFFF（卡片）
- **Light 主题文字**：#1C1C1E（主文字）、#8E8E93（次要文字）
- **Dark 主题背景**：#1C1C1E（深灰）、#2C2C2E（卡片）
- **Dark 主题文字**：#F2F2F7（主文字）、#8E8E93（次要文字）
- **强调色**：蓝色 #007AFF（Light）/#0A84FF（Dark）、橙色 #FF9500
